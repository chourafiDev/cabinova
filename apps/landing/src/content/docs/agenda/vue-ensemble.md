L’agenda affiche les rendez-vous de l’espace dans lequel vous travaillez. Toute l’équipe de l’espace peut le consulter et prendre des rendez-vous.

## Les cinq vues

| Vue | Pour quoi faire |
|---|---|
| **Jour** | Le détail d’une journée, heure par heure |
| **Semaine** | La vue par défaut, du lundi au dimanche |
| **Mois** | Une vue d’ensemble du mois |
| **Année** | Repérer les jours chargés |
| **Liste** | Les rendez-vous les uns sous les autres |

> [!NOTE] La vue Semaine n’est pas disponible sur petit écran. Sur téléphone, utilisez les vues Jour ou Mois.

## Se déplacer dans le temps

Les flèches changent de période. Le bouton avec la date du jour ramène à aujourd’hui.

## Filtrer par praticien

Le menu « Tous les praticiens » affiche l’agenda d’un seul médecin.

## Lire l’agenda

La couleur d’un rendez-vous indique son [statut](/docs/agenda/suivre-une-visite). Les heures de fermeture sont grisées. Une ligne marque l’heure actuelle sur les vues Jour et Semaine.

Cliquez sur un rendez-vous pour ouvrir son panneau : le patient, sa couverture, son solde, sa dernière visite et les actions possibles. L’agenda reste utilisable à côté, et cliquer sur un autre rendez-vous change simplement le panneau.
