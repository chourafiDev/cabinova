## Créer un rendez-vous

1. Cliquez sur **Nouveau rendez-vous**, ou directement sur un créneau de l’agenda.
2. Cherchez le patient par son nom, son téléphone, son CIN ou son numéro de dossier.
3. Choisissez le praticien, la date, l’heure et la durée.
4. Ajoutez si besoin le motif et une note pour l’accueil.
5. Cliquez sur **Ajouter**.

> [!TIP] Depuis le dossier d’un patient, **Prendre rendez-vous** ouvre le formulaire avec ce patient déjà choisi.

## Les règles à connaître

### Horaires d’ouverture

Un rendez-vous doit tenir entièrement dans les [horaires de l’espace](/docs/agenda/horaires). En dehors, il est refusé, sans exception. Le formulaire vous indique les horaires du jour.

### Double réservation

Si le praticien a déjà un rendez-vous sur ce créneau, Cabinova vous le signale, y compris lorsqu’il est dans un autre espace. Vous pouvez alors choisir **Réserver quand même**.

### Durée

La durée proposée est celle [réglée pour le cabinet](/docs/agenda/horaires#la-duree-par-defaut). Vous pouvez la changer pour chaque rendez-vous, de 10 minutes à 2 heures.

## Déplacer un rendez-vous

Faites glisser le rendez-vous vers un autre créneau. Si le créneau est déjà pris, un message propose de le déplacer quand même.

## Modifier ou annuler

Ouvrez le rendez-vous, puis utilisez **Modifier** pour changer ses détails. Pour l’annuler, choisissez **Annulé** dans le menu **Statut**.

> [!NOTE] Un rendez-vous terminé ne peut plus être modifié.
