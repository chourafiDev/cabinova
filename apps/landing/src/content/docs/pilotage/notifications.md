La cloche, en haut de l’application, signale ce qui demande votre attention. Elle se met à jour toutes les minutes.

## Ce qui est signalé

| Événement | Qui est prévenu |
|---|---|
| Un patient arrive en salle d’attente | Le médecin concerné |
| Un patient annule | Le médecin concerné |
| Un patient ne vient pas | Le médecin concerné et le médecin responsable |
| Un membre invité rejoint l’équipe | Le médecin responsable |
| Un devis ou une facture est à régler | Le médecin responsable |

Vous n’êtes pas prévenu de ce que vous avez fait vous-même.

## Lire ses notifications

Cliquez sur une notification pour ouvrir ce qu’elle concerne. **Tout marquer comme lu** vide le compteur. Les notifications sont conservées 90 jours.
