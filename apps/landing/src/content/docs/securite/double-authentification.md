La double authentification demande, en plus du mot de passe, un code à 6 chiffres affiché par une application sur votre téléphone. Elle est fortement recommandée, car votre compte donne accès à des données de patients.

## L’activer

1. Installez une application comme Google Authenticator, Microsoft Authenticator ou 1Password.
2. Dans **Paramètres › Mon profil**, cliquez sur **Activer la double authentification**.
3. Scannez le QR code, puis saisissez le code affiché.
4. Enregistrez vos codes de secours.

## Les codes de secours

Vous recevez 10 codes, utilisables une seule fois chacun, si vous n’avez plus votre téléphone. Ils ne sont affichés qu’une fois : copiez-les ou téléchargez-les, et gardez-les en lieu sûr.

> [!TIP] Quand il en reste peu, générez-en de nouveaux depuis votre profil. Les anciens cessent alors de fonctionner.

## Se connecter

Après votre mot de passe, saisissez le code affiché par l’application, ou un code de secours.

## Téléphone perdu

Connectez-vous avec un code de secours. Si vous n’en avez plus, demandez au médecin responsable de réinitialiser votre double authentification depuis [Équipe](/docs/cabinet/equipe). Il doit vérifier votre demande de vive voix : vous êtes alors déconnecté partout et prévenu par e-mail.

> [!NOTE] Le médecin responsable ne peut pas réinitialiser son propre compte : il utilise ses codes de secours ou [contacte le support](/docs/aide/support).

## L’exiger pour toute l’équipe

Le médecin responsable peut [l’exiger pour tout le cabinet](/docs/cabinet/equipe#exiger-la-double-authentification). Elle ne peut alors plus être désactivée.
