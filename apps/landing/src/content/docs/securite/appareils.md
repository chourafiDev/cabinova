## Vos appareils

Dans **Paramètres › Mon profil**, **Appareils connectés** liste les navigateurs où vous êtes connecté. Si vous n’en reconnaissez pas un, déconnectez-le, puis changez votre mot de passe. **Déconnecter les autres** ferme toutes vos autres sessions.

## Les sessions de l’équipe

Le médecin responsable voit chaque appareil connecté, personne par personne, dans **Paramètres › Sessions actives** : le navigateur, la dernière activité, la date de connexion et l’adresse IP.

Il peut déconnecter un appareil, ou utiliser **Tout déconnecter** pour un membre.

> [!WARNING] Un accès qui vous semble anormal ? Déconnectez-le, puis faites changer le mot de passe de la personne.
