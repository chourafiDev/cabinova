## Écrire au support

Envoyez un message à [support@cabinova.ma](mailto:support@cabinova.ma). Le bouton **Contacter le support**, en bas du menu de l’application, ouvre directement un e-mail.

## Pour une réponse plus rapide

Indiquez dans votre message :

- Le nom ou l’adresse de votre cabinet
- Ce que vous essayiez de faire
- Le message d’erreur affiché, avec une capture d’écran si possible

> [!WARNING] N’envoyez jamais votre mot de passe ni de données médicales de patients par e-mail. Le support ne vous les demandera pas.

## Avant d’écrire

Les [questions fréquentes](/docs/aide/faq) répondent aux demandes les plus courantes.
