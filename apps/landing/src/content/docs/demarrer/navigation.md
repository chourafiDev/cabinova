Trois moyens de vous déplacer rapidement : le menu, la palette de commandes et les raccourcis clavier.

## Le menu latéral

Il regroupe les modules par thème. Son contenu dépend de votre [rôle](/docs/demarrer/roles). En haut, le menu du cabinet donne accès aux paramètres et permet de changer d’[espace](/docs/cabinet/espaces). `Ctrl` + `B` (ou `⌘` + `B` sur Mac) l’affiche ou le masque.

## La palette de commandes

Appuyez sur `Ctrl` + `K` (ou `⌘` + `K` sur Mac), ou sur `/`, puis tapez ce que vous cherchez : une page ou une action. La recherche ne tient pas compte des accents.

## Les raccourcis clavier

Ils sont inactifs pendant la saisie dans un champ.

| Raccourci | Action |
|---|---|
| `Ctrl` + `K` ou `/` | Ouvrir la palette de commandes |
| `Ctrl` + `B` | Afficher ou masquer le menu |
| `?` | Afficher la liste des raccourcis |
| `G` puis `D` | Aller au tableau de bord |
| `G` puis `A` | Aller à l’agenda |
| `G` puis `P` | Aller aux patients |
| `G` puis `E` | Aller aux encaissements |

Dans le formulaire d’un patient, `Ctrl` + `Entrée` enregistre depuis n’importe quel champ.

## Thème clair ou sombre

Le bouton en forme de lune, dans l’en-tête, change le thème de l’application.
